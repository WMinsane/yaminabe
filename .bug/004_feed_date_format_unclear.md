# 004 フィード各行右側の "4/5" 表示が何を示すか不明

- Status: Fixed
- 報告日: 2026-04-12
- 確認日: 2026-04-12
- 影響範囲: フィード画面（FeedView, DenseItem）

## 現象

フィード一覧の各記事行の右端に "4/5" のような数値が表示されているが、ユーザーにとって意味不明（比率に見える）。実際は記事の公開日(M/D形式)。

## 期待動作

公開日であることが一目でわかる表示（例: "4月5日" / "4/5(土)" / 相対表記 "3日前" 等）。

## 修正方針候補

- A: `4月5日` 形式
- B: `4/5(土)` 曜日付
- C: 相対表記 `3日前`（7日以上前は日付）
- D: 日付アイコン（📅）+ MM/DD
