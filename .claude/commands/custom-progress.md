# 進捗確認とリカバリ

## 手順

1. `.docs/schedule.md` を読み込む
2. 現在日付から「今どの週（W1〜W6）にいるか」「どのフェーズが完了しているべきか」を判定する
3. タスク分解セクションの `[x]` / `[ ]` を集計し、以下を出力する:

## 出力フォーマット

```
## 進捗サマリー（{現在日付}）

**現在の週**: W{N}（{期間}）
**予定フェーズ**: {該当フェーズ}
**MVP期限**: 2026-04-30

### フェーズ別進捗

| フェーズ | 予定週 | 状態 | 完了タスク | 残タスク |
|---------|--------|------|-----------|---------|

### 判定
- ⏳ 予定通り / 🔴 遅延あり
```

4. **遅延がある場合**、以下の優先順でリカバリ案を提示する:
   - タスクの並行化（同週に詰められるものがないか）
   - スコープ削減（MVP最小画面の厳格化、Medium以下の先送り）
   - フェーズ統合（軽量フェーズの同週消化）
5. リカバリ案を提示したら、schedule.mdへの反映要否をユーザーに確認する
