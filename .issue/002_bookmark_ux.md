# 002 ブックマーク導線が不明瞭

- Status: Closed
- 起票日: 2026-04-12
- 完了日: 2026-04-12

## 決定

- A案（☆/★トグル）採用
- フィード・ライブラリ双方からトグル可能
- 管理側でsoft-delete済コンテンツはライブラリ非表示（A案、`content: { deletedAt: null }` フィルタ維持）

## 背景

現状フィード画面に明示的な「ブックマーク」操作UIがなく、ユーザーがブックマークの行い方が分からない。ライブラリ画面ではブックマーク種別フィルタが存在するが、登録手段がない。

## 要望

フィード画面から直接ブックマーク登録できるUI。

## 実装方針候補

- A: 各記事行末に星アイコン（☆/★トグル）
- B: 記事タイトル長押し or 右クリックメニュー
- C: 記事クリック先（外部サイト）に行く前に確認モーダルで「ブックマーク」選択肢
- D: ライブラリ画面のメモ同様、フィードからモーダルでブックマーク追加

## 技術メモ

- `UserAction.isBookmarked` `bookmarkedAt` を更新するServer Action `toggleBookmark(contentId)` を追加
- 既存の`recordClick`と同じパターン
